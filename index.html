🥇 #1 — Flagship Project
METAR Multi-Airport Prediction System
metar-predict · metar-predict-v2 · metar-db · metar-dashboard
GitHub

End-to-end ML system that predicts airport temperature readings from live METAR data. Built a custom data pipeline that ingests real-time METAR reports via WIS2/MQTT and stores them in a 700MB+ SQLite database. Trained three separate ML models (XGBoost, LightGBM, CatBoost) per airport with chronological cross-validation — covering 15+ airports globally including RPLL (Manila), RJTT (Tokyo), WSSS (Singapore), EDDM (Munich), EGLC (London City), and more. Features a live dashboard with predictions vs actuals, confidence intervals, and similar-day analysis. Built for use on Polymarket temperature prediction markets.
